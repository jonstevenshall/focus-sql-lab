What is this?

FOCUS is an open standard for cloud and software billing data: one agreed shape for a bill, so that cost data from cloud providers, SaaS vendors and others can be read and compared the same way.

This lab is a place to get to know FOCUS properly. Not just what the model says today, but how it got here: the proposals, the debates, the ideas that didn't make it, and what the people behind it learned from the users who asked for each change.

What you can do here

  • Data model. Explore the FOCUS datasets and how they join. Click any dataset, column, rule or condition for a plain-English explanation, the specification's own wording, its requirements exactly as written, and its history: the pull requests that shaped it, what was argued, how each conversation ended, and what was never merged.
  • Query. Run the specification's own example queries, exactly as published, against real sample data, right in your browser. Switch between the official sample, two proposed newer ones and the spec's worked examples to see which joins hold up.
  • Evidence. See how FOCUS decides what to build: the problems users raised, who asked, how the working group found out, and what it traded off.

Where to start

In the Data model, open Cost and Usage, then BilledCost. Its history tells the story of a year-long debate about what a cost really is.

Good to know

  • Everything runs in your browser. There's no sign-in and nothing is stored. The MCP server tab sends its requests from your browser to the FinOps Foundation's server at focus.finops.org.
  • It's built from public material: the FOCUS specification and its GitHub history, and the FinOps Foundation's sample data. It isn't affiliated with the FinOps Foundation.
  • The plain-English summaries were written with AI from those sources. The specification's own text and links to every source are always alongside.
  • It's open source: see it on GitHub.

About the data

Sources and cleaning
  • Names tagged FOCUS are the specification's. Names tagged lab, and columns with a dotted underline, were made by this lab: hover over one to see why.
  • cau_sample is the FinOps Foundation's FOCUS-Sample-Data: anonymised FOCUS 1.0 data from AWS, Microsoft, Oracle and a little Google. Costs are anonymised: read the method, not the money.
  • It is not FOCUS 1.5 data. So that 1.5 queries can run on it, the lab added every 1.5 column it lacks, empty. It derived ServiceProviderName and HostProviderName from ProviderName, PublisherName and InvoiceIssuerName using the spec's migration guidance. The 1.0 columns that later versions removed are kept.
  • The sample writes missing values as the text NULL. These were loaded as nulls.
  • cau_pr7 and cc_pr7 (FOCUS 1.3), and cau_pr5, cc_pr5, inv_pr5 and bp_pr5 (FOCUS 1.4), are sample data proposed in open FOCUS-Sample-Data pull requests #7 and #5 (a draft). FOCUS hasn't accepted either. Values are as published at each pull request's latest commit, typed to the 1.5 column types. The lab added the 1.5 columns each one lacks, empty.
  • cau_examples and the other _examples tables come from the specification's worked-example CSVs. Each file is a separate scenario, so filter by x_ExampleFile before you add anything up. Some files used the text null or currency text such as $10,000.00 in Decimal columns. These were cleaned on load.
  • Decimal columns are 64-bit floating point, one of the precisions the spec allows. Sums of charges and credits can leave tiny remainders instead of exactly zero.

The FinOps Foundation runs an MCP server that lets AI assistants look up FOCUS content: the specification, its columns, example queries, use cases, providers and the documentation on focus.finops.org. It doesn't hold billing data. This tab sends requests from your browser straight to that server and shows the replies as it returned them. The lab doesn't run the server or change what it sends.

Address: https://focus.finops.org/wp-json/focus/v1/mcp (HTTP, no sign-in), described on the server's page. To add it to Claude Code: claude mcp add --transport http focus https://focus.finops.org/wp-json/focus/v1/mcp. Other MCP clients take the same address.
